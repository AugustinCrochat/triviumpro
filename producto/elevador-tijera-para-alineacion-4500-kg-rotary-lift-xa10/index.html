Ficha Técnica

Elevador Tijera para Alineación X10

Rotary Lift

Con plataformas de 4800 mm de largo, placas deslizantes de gran tamaño y cavidades para medidores de radio fácilmente ajustables, el XA10 se adapta a una amplia gama de distancias entre ejes.

Características Principales

  • Cerraduras mecánicas con 18 posiciones de bloqueo, se activan automáticamente y se liberan neumáticamente.
  • Calzos automáticos para las ruedas traseras, se activan al levantar el elevador y se liberan al bajar.
  • Marco de base completo, fácil de instalar.
  • Sistema de nivelación hidráulica mediante un dispositivo de sincronización patentado para garantizar plataformas elevadoras niveladas constantemente.
  • Tope de las ruedas delanteras de la plataforma.
