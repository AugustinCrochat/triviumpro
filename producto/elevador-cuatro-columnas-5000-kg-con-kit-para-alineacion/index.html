Elevador 4 Columnas PL-FS50 con Kit para Alineación - 5000 kg

Unite

Elevador electro-hidráulico de 4 columnas con capacidad para 5 toneladas. Ideal para talleres que requieren alineaciones precisas y un diseño de alta durabilidad.

Características Principales

  • Plataformas de perfil bajo con rampas cortas, ahorran espacio cuando están completamente bajadas.
  • Plataforma de una sola pieza, con soldadura única, asegura durabilidad extrema.
  • Bloqueo mecánico automático durante el proceso de elevación.
  • Altura ajustable para trabajar con diferentes tipos de vehículos.
  • Incluye kit de alineación: platos deslizantes traseros y huecos para platos opcionales.
  • Rolling Jack incluido para mayor funcionalidad.
